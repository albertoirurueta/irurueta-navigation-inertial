= World Magnetic Model (WMM)
:description: Overview of the World Magnetic Model (WMM) package for computing Earth's magnetic field magnitude, declination, and dip at a given position and date.
:keywords: World Magnetic Model, WMM, magnetic declination, dip inclination, geomagnetic field, WorldMagneticModel, WMMLoader

NOTE: This documentation was generated with the assistance of AI. Please report any inaccuracies.

The `com.irurueta.navigation.inertial.wmm` package estimates the Earth's magnetic flux density at a
given position and date, using the U.S./U.K. https://www.ngdc.noaa.gov/geomag/WMM/[World Magnetic Model
(WMM)] — see xref:reference.adoc#wmm-site[[wmm-site\]]. It is used both as an independent heading
reference (see xref:estimators/attitude.adoc[`AttitudeEstimator`]) and as an input to magnetometer
calibration (see xref:calibration/index.adoc[]).

[WARNING]
====
This library bundles a *default* WMM coefficient file (`wmm.cof`, currently WMM-2025, valid
2025.0-2030.0 — see xref:wmm/spherical-harmonic-model.adoc[]). Every WMM release expires after 5 years:
past its valid period, the model's secular-variation extrapolation drifts and declination/dip estimates
become unreliable. Applications running past 2030 (or bundling this library long-term) should download
the current release from
https://www.ncei.noaa.gov/products/world-magnetic-model/wmm-coefficients[NOAA/NCEI's WMM coefficients
page] and load it explicitly with `WMMLoader`, instead of relying on the bundled default — see
xref:wmm/spherical-harmonic-model.adoc[] for how to load a custom coefficient file.
====

== What the WMM provides

At any given latitude, longitude, height, and date, the Earth's magnetic field can be described by three
independent quantities:

[cols="1,3",options="header"]
|===
|Element |Meaning

|*Magnitude* (intensity)
|Total field strength, roughly 30 microtesla (µT) at the equator up to about 60 µT near the poles.

|*Declination*
|The bearing of the magnetic field from true north — the angle a compass needle's reading must be
corrected by to get true heading.

|*Dip* (inclination)
|The angle the field makes below the local horizontal plane — essentially the "magnetic latitude,"
typically within about 10° of the geodetic latitude.
|===

image::wmm/geomagnetic-elements.svg[Elements of the geomagnetic field: declination and dip versus horizontal and total intensity,520,380]

Declination is the only one of the three needed to convert a magnetometer heading measurement into true
heading (see xref:estimators/attitude.adoc[`AttitudeEstimator`]). It is *not* constant: it drifts slowly
over years (secular variation) and varies significantly with location, which is why a global model like
the WMM — rather than a single fixed value — is needed.

== From position and date to field components

The evaluation chain used by `WMMEarthMagneticFluxDensityEstimator` has four stages. Each one is derived
in detail in xref:wmm/spherical-harmonic-model.adoc[]; this section only states the equations in order.
The conventions follow the WMM technical report (xref:reference.adoc#wmm-site[[wmm-site\]]) and
xref:reference.adoc#book-groves[[book-groves\]], where the same NED quantities are used for navigation.

[mermaid]
....
flowchart LR
    A["Geodetic position\n(latitude φ, longitude λ, height h)"] -->|"WGS84 ellipsoid\n(a, b)"| B["Geocentric spherical\n(radius r, latitude φ', same λ)"]
    B -->|"Gauss coefficients at\ndecimal year t"| C["Spherical field components\n(B_r, B_θ, B_φ)"]
    C -->|"rotate by ψ = φ - φ'"| D["Geodetic NED components\n(X, Y, Z)"]
    D --> E["H, F, declination D,\ndip I"]
....

*1. Geodetic to geocentric spherical coordinates.* The WGS84 ellipsoid has semi-major axis stem:[a] and
semi-minor axis stem:[b]. For a point at geodetic latitude stem:[\varphi] and ellipsoidal height
stem:[h], define

[stem]
++++
q = \sqrt{a^{2}\cos^{2}\varphi + b^{2}\sin^{2}\varphi}, \qquad
\tan\varphi' = \frac{hq + b^{2}}{hq + a^{2}}\,\tan\varphi, \qquad
r^{2} = h^{2} + 2hq + \frac{a^{4}\cos^{2}\varphi + b^{4}\sin^{2}\varphi}{q^{2}}
++++

where stem:[\varphi'] is the geocentric latitude (the colatitude used by the harmonic sum is
stem:[\theta = 90^\circ - \varphi']) and stem:[r] is the distance to the Earth's centre. Longitude is the
same in both systems. The angle between the geodetic and geocentric vertical is

[stem]
++++
\psi = \varphi - \varphi', \qquad
\cos\psi = \frac{h + q}{r}, \qquad
\sin\psi = \frac{(a^{2}-b^{2})\cos\varphi\sin\varphi}{r\,q}
++++

These are the quantities the implementation keeps as `ct`/`st` (cosine/sine of the colatitude) and
`ca`/`sa` (cosine/sine of stem:[\psi]). At sea level the latitude relation reduces to
stem:[\tan\varphi' = (b^{2}/a^{2})\tan\varphi]; the two latitudes differ by at most about
stem:[0.19^\circ], at mid-latitudes.

*2. Field in geocentric spherical components.* With the coefficients evaluated at the requested time (see
step 4 below), the harmonic sum of xref:wmm/spherical-harmonic-model.adoc[] yields
stem:[(B_r, B_\theta, B_\phi)] at stem:[(r, \theta, \lambda)].

*3. Field components X, Y, Z.* Rotating by stem:[\psi] about the east axis gives the north, east and down
components (the geomagnetic elements stem:[X], stem:[Y], stem:[Z], identical to
stem:[B_N], stem:[B_E], stem:[B_D]):

[stem]
++++
\begin{bmatrix} X \\ Y \\ Z \end{bmatrix} =
\begin{bmatrix} -B_\theta\cos\psi - B_r\sin\psi \\ B_\phi \\ B_\theta\sin\psi - B_r\cos\psi \end{bmatrix}
++++

The elements in the table above follow from them:

[stem]
++++
H = \sqrt{X^{2}+Y^{2}}, \qquad
F = \sqrt{H^{2}+Z^{2}}, \qquad
D = \operatorname{atan2}(Y, X), \qquad
I = \operatorname{atan2}(Z, H)
++++

where stem:[H] is the horizontal intensity, stem:[F] the total intensity (the *Magnitude* above), stem:[D] the
declination (positive east of true north) and stem:[I] the dip (positive when the field points downward).
The inverse relations, used when the three scalars are known and the vector is wanted, are
stem:[X = F\cos I\cos D], stem:[Y = F\cos I\sin D] and stem:[Z = F\sin I]; see
xref:wmm/earth-magnetic-flux-density.adoc[].

*4. Secular variation over time.* Each Gauss coefficient is extrapolated linearly from the model epoch
stem:[t_0] to the decimal year stem:[t] with its published yearly rate:

[stem]
++++
g_{n}^{m}(t) = g_{n}^{m}(t_{0}) + (t - t_{0})\,\dot g_{n}^{m}, \qquad
h_{n}^{m}(t) = h_{n}^{m}(t_{0}) + (t - t_{0})\,\dot h_{n}^{m}
++++

Because the harmonic sum is linear in the coefficients, the components stem:[X], stem:[Y] and stem:[Z] also
vary linearly in stem:[t] (stem:[\dot X], stem:[\dot Y], stem:[\dot Z] are the same sum evaluated with
stem:[\dot g] and stem:[\dot h]). The derived angles do not: differentiating the relations of step 3 gives

[stem]
++++
\dot D = \frac{X\dot Y - Y\dot X}{H^{2}}, \qquad
\dot I = \frac{H\dot Z - Z\dot H}{F^{2}}, \qquad
\dot H = \frac{X\dot X + Y\dot Y}{H}
++++

The estimator does not expose these rates as methods; evaluate it at two dates to obtain them numerically.

== Classes

[cols="1,3",options="header"]
|===
|Class |Role

|`WorldMagneticModel`
|Holds the loaded Gauss coefficients (main field + secular variation) and derived normalization factors
for one 5-year WMM release.

|`WMMLoader`
|Parses a WMM coefficient file (`.cof`) — from a resource, file, or URL — into a `WorldMagneticModel`.

|`WMMEarthMagneticFluxDensityEstimator`
|Evaluates the spherical-harmonic model at a given position/date to get declination, dip, intensity, and
the full NED magnetic flux density vector. This is the actual WMM algorithm.

|`EarthMagneticFluxDensityEstimator`
|A much simpler helper: builds a NED magnetic flux density vector directly from an already-known
magnitude/declination/dip (e.g. supplied by the caller, without needing the full WMM coefficient set).

|`NEDMagneticFluxDensity`
|Data container for magnetic flux density resolved about north, east, down axes.
|===

[mermaid]
....
flowchart LR
    A[".cof coefficient file\n(NOAA/NGA/BGS release)"] -->|WMMLoader| B["WorldMagneticModel\n(Gauss coefficients)"]
    B --> C["WMMEarthMagneticFluxDensityEstimator\n(spherical harmonic evaluation)"]
    D["latitude, longitude,\nheight, date"] --> C
    C --> E["declination, dip, intensity,\nNEDMagneticFluxDensity"]
    E --> F["AttitudeEstimator\n(heading correction)"]
    E --> G["Magnetometer calibration"]
....
